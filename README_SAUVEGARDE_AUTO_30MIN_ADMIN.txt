SAUVEGARDE AUTOMATIQUE 30 MINUTES - ADMIN

Cette version ajoute une sauvegarde automatique fiable :

- Toutes les 30 minutes.
- Uniquement quand un compte administrateur est connecté.
- Le site doit rester ouvert sur le PC administrateur.
- La sauvegarde apparaît dans "Sauvegardes jour".
- Un fichier JSON se télécharge automatiquement sur le PC admin.
- Nom du fichier exemple :
  sauvegarde-auto-2026-05-03-14h30.json

Important :
Chrome peut bloquer les téléchargements multiples automatiques.
Si Chrome demande l'autorisation, clique "Autoriser" pour ce site.

Sécurité :
- Les sauvegardes vides sont bloquées.
- Les données sont fusionnées avant envoi Supabase.
- Une copie locale de sécurité est gardée.
